# F OS Launcher

لانچر اندروید با والپیپر «تیلت» (الهام‌گرفته از solotilt.com) و شخصی‌سازی گسترده.

## ساخت برنامه
1. Android Studio (نسخه Koala یا جدیدتر) را باز کنید → **Open** → پوشه‌ی `FOS` را انتخاب کنید.
2. صبر کنید Gradle Sync تمام شود (اینترنت لازم است؛ JDK 17 همراه Android Studio است).
3. گوشی را با USB وصل کنید (Developer options → USB debugging) و دکمه‌ی ▶ Run را بزنید.
   برای فایل APK: Build → Build Bundle(s)/APK(s) → Build APK(s).

## انتخاب به‌عنوان لانچر
بعد از نصب، دکمه‌ی Home را بزنید و **F OS** را انتخاب کنید (Always)، یا:
تنظیمات F OS ← «زبان و درباره» ← «انتخاب F OS به‌عنوان لانچر پیش‌فرض».

## کار با لانچر
- کشیدن به بالا: کشوی برنامه‌ها  |  کشیدن به پایین: اعلان‌ها (قابل تغییر)
- نگه داشتن روی فضای خالی: منوی سریع (والپیپر، آیکون‌ها، تنظیمات)
- نگه داشتن روی هر آیکون: افزودن/حذف از صفحه اصلی یا داک، جابه‌جایی، تغییر نام، پنهان کردن، حذف
